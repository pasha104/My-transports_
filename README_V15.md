# BUSPHOTO Interactive v15

- Троллейбусам при покупке автоматически назначается уникальный бортовой номер строго из 4 цифр.
- Добавлены регионы РФ для загрузки остановок: Смоленская область, Московская область, Москва, Санкт-Петербург.
- Карточка выезда теперь поддерживает несколько выездов и дни недели: отдельные дни, все будни, все выходные, все дни.
- В карточке показывается расчётное время маршрута, если геометрия маршрута рассчитана.
- Движение ТС по карточке учитывает расписание: вне окна выезда ТС находится в парке.
- Начисление +100 р. происходит за завершённый оборот во время активного выезда.
