# BUSPHOTO v14 — регионы остановок + слежение за ТС

Изменения:
- В интерактиве добавлена вкладка «🛰️ Следить за ТС» с выбором ТС и автоматическим центрированием камеры.
- ТС на одном маршруте разводятся по времени движения, чтобы не стоять в одной точке.
- Добавлен выбор региона остановок: Минск, 6 областей и все 118 районов Беларуси.
- Остановки региона загружаются по одному запросу и кэшируются в localStorage.
- Убрана постоянная полная дедупликация всего массива остановок при каждом чтении, что важно для больших наборов данных.
- Существующий интерфейс для ТВ из v13 не расширялся дополнительными ТВ-элементами.
