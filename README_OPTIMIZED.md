# BUSPHOTO — оптимизированная версия

Исправлено:
- Telegram/backend полностью убраны из статической версии.
- Карта Leaflet загружается только при открытии раздела «Карта».
- Таймер игрового состояния уменьшен до одного лёгкого цикла раз в 15 секунд.
- Анимация ТС на карте ограничена ~4–5 обновлениями/с.
- Начисление 100 ₽ за каждое прибытие на конечную считается по реальному времени и восстанавливается после закрытия сайта.
- Мобильная шапка и меню больше не должны разъезжаться по ширине.
- Добавлен service worker для офлайн-загрузки самого сайта; карта и внешние OSM/OSRM/Overpass сервисы требуют интернет.
- Добавлен cache-busting для обновлённых JS/CSS.
- Импорт/экспорт JSON базы остаётся локальным.

Начальная игра по-прежнему 50 000 ₽, а сохранённый localStorage не заменяется, если он уже существует.
