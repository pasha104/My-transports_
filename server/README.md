# BUSPHOTO Telegram API

## 1. Установка
Требуется Node.js 20+.

```bash
npm install
```

## 2. Настройка
Скопируй `.env.example` в `.env` и вставь токен BotFather в `BOT_TOKEN`.
Токен **никому не отправляй и не добавляй в GitHub**.

## 3. Запуск
```bash
npm start
```

Проверка:
`GET /health`

## 4. Привязка сайта
Сайт автоматически получает шестизначный код после регистрации. Отправь боту:

`/link 123456`

После привязки бот и сайт используют одну базу.

## Важно
Для публичного сайта сервер нужно разместить на Render/Railway/Fly.io/VPS или другом Node.js-хостинге. GitHub Pages остаётся только фронтендом.
