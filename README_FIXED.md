# BUSPHOTO — исправленная версия

Что исправлено:
- создание маршрутов оставлено только на карте; ручная форма в разделе «Маршруты» удалена;
- карточки выезда полностью удалены из интерфейса и логики; ТС двигаются по маршруту напрямую после назначения;
- гайд удалён;
- игровой трамвайный каталог и загрузчик трамвайных маршрутов OSM удалены;
- исправлена таблица гаража: теперь 8 колонок совпадают с данными строки;
- купленные в интерактиве ТС отображаются в основной «Базе данных» как записи «Мой гараж»;
- старые данные `serviceCards` автоматически удаляются из игрового состояния;
- зарплата ТС продолжает начисляться офлайн, без карточек;
- добавлена версия локальных CSS/JS-ресурсов (`?v=20260819-fixed1`) и автоматическая очистка старого Service Worker/cache, чтобы браузер не показывал старую сборку;
- добавлен `sw.js`, который очищает старый кэш и сам отключается, если старый Service Worker ещё зарегистрирован.

## Важно
Игровой гараж и экспортируемая основная БД остаются разными хранилищами. Купленные игровые ТС только отображаются в основной БД как «Мой гараж» и не попадают в экспорт основной БД.

После загрузки файлов на GitHub сделай commit в ветку `main`. Render должен автоматически создать новый deploy.

- исправлен `ReferenceError: escapeHtml is not defined`: `escapeHtml` перенесена в общий JS, который загружается раньше интерактива;
- версия ресурсов повышена до `fixed2`, чтобы браузер не использовал старый JS из кэша.

- В верхнем меню оставлены только три раздела: «База данных + поиск», «Список моделей» и «Интерактив». Ссылка «Создать ТС для интерактива» убрана из главной навигации.
