MY-TRANSPORTS — САМЫЙ ПРОСТОЙ РЕЖИМ

ТЕБЕ НЕ НУЖНЫ:
- Supabase
- SQL
- базы Supabase
- ключи Supabase

1. ЗАГРУЗИ ПРОЕКТ НА GITHUB
   Загрузить все файлы из этой папки в свой репозиторий.

2. TELEGRAM / RENDER
   В Render открой My-transports-telegram.
   Environment → проверь только:

   BOT_TOKEN = токен твоего Telegram-бота

   Больше ничего добавлять НЕ НУЖНО.

   После изменения нажми Save, rebuild, and deploy.

3. САЙТ
   Открой GitHub Pages.
   Внизу сайта появится кнопка 👤 Профиль.

4. TELEGRAM
   Нажми 👤 Профиль → 🤖 Подключить Telegram.
   Сайт покажет код вида MY-XXXXXX.
   Отправь этот код своему Telegram-боту.

5. ГОТОВО
   После ответа бота Telegram подключён к этому профилю.

ВАЖНО:
- Интерактив работает сразу из localStorage.
- Supabase не нужен.
- Основная база ТС не связана с Telegram-профилем.
- Если Render уснёт или перезапустится, Telegram-привязку может понадобиться сделать заново.
- Данные игры в браузере не удаляются из-за перезапуска Render.
