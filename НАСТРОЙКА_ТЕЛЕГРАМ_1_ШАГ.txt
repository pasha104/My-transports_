MY-TRANSPORTS — НАСТРОЙКА В 5 ШАГОВ

1. В GitHub загрузи ВСЕ файлы из этой папки.
2. В Render создай Web Service из папки telegram-server.
3. Build Command: npm install
4. Start Command: npm start
5. В Environment добавь:
   BOT_TOKEN = токен бота
   SITE_ORIGIN = https://pasha104.github.io
   SITE_URL = https://pasha104.github.io/My-transports_/interactive.html

После деплоя:
Сайт → Интерактив → 👤 Профиль → 🤖 Подключить Telegram.
Полученный MY-XXXXXX отправь своему боту.

ВАЖНО: токен бота никому не отправляй.
Supabase для этой версии НЕ НУЖЕН.
