НАСТРОЙКА МАРШРУТОВ

1. Все маршруты создаются и строятся только через интерактив → 🗺️ Карта.
2. В карте включи режим 🛣️ Сборка маршрута.
3. Выбери/создай маршрут, добавь остановки по порядку и при необходимости контрольные точки.
4. Нажми «Построить по дорогам», затем «Сохранить маршрут».
5. Обратное направление задаётся отдельным связанным маршрутом/pairedRouteId; карточка только использует уже сохранённые маршруты.
6. В creating_card.html маршрут не создаётся — там он только выбирается для карточки.
7. В Telegram нет меню карты и создания маршрутов: для построения маршрутов используется только сайт и его карта.
