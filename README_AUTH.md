# My-transports — accounts + Telegram

В этой версии добавлен пользовательский аккаунт и облачная синхронизация интерактива.
См. `telegram-server/README.md` и `supabase_schema.sql`.

Пока карта и создание маршрутов не менялись. Основные личные данные интерактива
(баланс, гараж, маршруты, карточки, история) привязываются к аккаунту.


## Оптимизация загрузки v2026-08-21
Интерактив запускается сразу из localStorage; облачная синхронизация Supabase выполняется в фоне без блокирующей перезагрузки. Выплата в 12:00 считается по часовому поясу Europe/Minsk без внешнего API времени.
