🗺️ Карта Минска и Минского района

Выбирай область или район. Загруженные регионы сохраняются в браузере, поэтому повторно скачивать их не нужно.
Начни вводить название — поиск работает по уже загруженным остановкам.
Готово
🚍 Режим местоположения ТС: остановки и линии скрыты, на карте остаётся только движущийся транспорт. Нажми на ТС или выбери его справа.
Выбор: нажми на остановку, чтобы увидеть её данные. Своя остановка: кликни по карте и задай название. Сборка маршрута: включи режим 🛣️ и кликай по остановкам по порядку. Точки увеличены для удобного нажатия на телефоне. Своя остановка может быть классической или пунктом разворота: пункт разворота не считается конечной, а на конечной ТС делает короткую стоянку перед сменой направления. При необходимости нажми «➕ Выбрать для маршрута» в карточке остановки. Затем выбери/создай маршрут и нажми «Построить по дорогам». Карта использует данные OpenStreetMap; атрибуция показывается непосредственно на карте.

🎯 Контрольные точки
Кликай остановки по порядку от первой конечной до второй. Для сложных участков включи «🎯 Контрольная точка» и расставь точки на дороге в нужном порядке — построение будет проходить через них. После создания маршрут автоматически получает первую и последнюю остановку как конечные, а обратное направление строится по той же линии в обратную сторону.

🛰️ Следить за ТС

Выбери ТС прямо здесь. Камера карты будет следить за ним, а текущий маршрут и состояние берутся из его активной карточки.
Выбери ТС для слежения.
