# BUSPHOTO Interactive v18

Изменения:
- В одной карточке выезда можно задавать несколько строк/смен за один день и разные маршруты.
- Для каждого маршрута автоматически рассчитываются отправление с конечной, повторные рейсы, последнее прибытие и заезд в парк.
- Добавлена проверка пересечения расписаний, чтобы одно ТС не оказалось одновременно на двух маршрутах.
- История прибытия на конечную теперь содержит дату, точное время, ТС, номер маршрута, конечную и оплату +100 р.
- При офлайн-периоде добавляется отдельная строка с общей суммой выплат за пропущенные прибытия.
- В финансах показываются все модели, которые уже можно купить на текущий баланс.
- Добавлена настройка email-уведомлений. На статическом GitHub Pages используется mailto: для подготовки письма; полностью автоматическая отправка без участия пользователя требует внешнего почтового сервиса/бэкенда.
