Я НЕ ПЕРЕДЕЛЫВАЛ ОСНОВНОЙ САЙТ И НЕ ТРОГАЛ БАЗУ ДАННЫХ.

Оставлено:
- магазин;
- мои ТС / гараж;
- создание карточки ТС;
- финансы;
- история;
- диспетчерская;
- статистика ТС;
- обслуживание.

Из основного меню убраны только кнопки карты и маршрутов, как ты просил.
Код карты/маршрутов внутри проекта не удалён, чтобы не сломать уже созданные данные и карточки.

ДОБАВЛЕНО:
1. Профиль → подключение Telegram кодом MY-XXXXXX.
2. Telegram-меню: баланс, ТС, карточки, ремонт, статистика, профиль, сайт.
3. Сайт отправляет на Telegram-сервер безопасную копию состояния игры для меню бота.
4. Несколько пользователей могут подключаться отдельно: у каждого свой local-профиль и свой chat_id.
5. Ремонт теперь НЕ бесплатный и НЕ мгновенный.
   Стоимость зависит от повреждения.
   Время ремонта тоже зависит от повреждения.
   Пока ТС ремонтируется, оно не восстанавливается мгновенно.
6. После окончания времени ремонта состояние автоматически становится 100%.
7. Если денег недостаточно — ремонт не запускается.
8. Команду ремонта можно нажать в Telegram; сайт заберёт команду и запустит ремонт при открытом/обновлённом сайте.

ВАЖНО:
- Supabase для Telegram в этой версии не нужен.
- Токен бота хранится только в Render Environment Variables.
- Telegram-сервер хранит состояние в памяти. Если бесплатный Render полностью перезапустится, привязка/снимок могут потребовать повторной синхронизации.
