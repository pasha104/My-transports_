# BUSPHOTO Interactive v17

Изменена карточка выезда:
- выбор ТС, дней, маршрута и обеих конечных;
- время выезда из парка задаётся вручную;
- отправление с выбранной конечной рассчитывается автоматически по времени подъезда от парка;
- задаётся «Работать до», включая время после полуночи;
- последнее прибытие и заезд в парк рассчитываются автоматически;
- показывается пример расписания рейсов на смену;
- один ТС может иметь несколько строк в одной карточке и работать по разным маршрутам в разные дни;
- каждый фактический приход на конечную каждого рейса даёт +100 ₽;
- офлайн-начисления используют уникальные отметки прибытия и не дублируют уже выплаченные рейсы;
- после окончания смены ТС физически едет в парк, а не исчезает.
