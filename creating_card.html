🗓️ Карточка ТС

← Вернуться в интерактив
Карточка создаётся отдельно от интерфейса интерактива. Она использует тот же гараж, маршруты и localStorage, поэтому созданная здесь карточка сразу сохраняется для интерактива.

💾 Сохранение карточек ТС

Можно сохранить карточку отдельно в файл JSON, а потом импортировать её обратно. Это удобно для резервной копии, переноса карточки или восстановления после очистки данных браузера.

3. Маршруты за день

Один маршрут: ТС выезжает, делает рейсы туда/обратно по связанным трассам до указанного времени и затем возвращается в парк.

4. Время работы

Выбери ТС и маршрут.

5. Интервалы движения

Здесь настраивается выпуск автобусов по времени суток. Интервал — через сколько минут должен отправляться следующий автобус. Количество ТС можно задать вручную или рассчитать автоматически по полному циклу «туда → пауза → обратно → пауза».
Выбери маршрут — количество будет рассчитано автоматически.
