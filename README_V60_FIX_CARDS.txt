BUSPHOTO v60 — карточки выезда + типы автобусных маршрутов

ИСПРАВЛЕНО:
1. Созданные карточки выезда теперь отображаются в creating_card.html.
2. Добавлена кнопка «Проверить карточку» с полным расписанием:
   - ТС;
   - маршруты и этапы;
   - дни недели;
   - выезд из парка;
   - отправление;
   - последнее прибытие;
   - возврат в парк;
   - количество рейсов.
3. Добавлена кнопка «Изменить». Карточка открывается в режиме редактирования.
4. После сохранения редактирования существующая карточка обновляется, а не создаётся копия.
5. Из интерактива карточку можно проверить или открыть для изменения через creating_card.html.
6. Добавлена поддержка открытия редактора карточки через ?edit=ID.
7. Для автобусных маршрутов на карте добавлен тип:
   - Городской
   - Пригородный
   - Междугородний
8. Тип маршрута сохраняется в routeServiceType и показывается рядом с маршрутом.
9. При выборе существующего автобусного маршрута его тип автоматически подставляется в редактор.
10. При сохранении/перестроении выбранного автобусного маршрута тип сохраняется.

ВАЖНО:
Существующие карточки и маршруты не удаляются. Старые маршруты без routeServiceType автоматически получают «Городской».
